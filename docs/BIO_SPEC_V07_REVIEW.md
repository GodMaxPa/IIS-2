## 2. Стартовая цепочка: проверка на замкнутые зависимости

Все рецепты §22 (W01–W11, B01–B29, L01–L13, A01–A12, F01–F09, сосуды, плёнка, P01/P03) заданы данными в `tools/bio/recipe_graph_v07.py`. Старт — ванильный мир без машин Кибера плюс то, что §22.2 даёт на челноке: ядро, карман, посев, N0.

**Результат:**

1. **Со всеми обходами v0.7 достижимы все 98 узлов, колец нет.** Порядок: N0 из стартового запаса → ПФ (L01) и гель (B06) → каркас и подложка → мягкая ткань (B12) и G0 (L10) → мембрана → ложе A01 → ULV-органы (A02, F02, F05) → мышечный узел и LV-органы на ULV-ложе → ручные N1/E1/G1 → F06 → хитин и камера перестройки.
2. **Без переходных обходов недостижимы 46 узлов.** Начиная с мембраны: A01 нужна мембрана, а мембрану растят в A01. Это настоящее кольцо, и его рвёт только оговорка «первое A01 — на ручной подложке». Так же только обходы открывают A03 (гнездо нужно для самого себя) и N1/E1/G1 (их делает только питательная железа F06, а её саму растят на G1). **Обходы спецификации обязательны, а не удобство.**
3. Цепочка опирается на четыре вещи, которых в v0.7 нет (проверено отключением каждого допущения):

| Не описано в v0.7 | Если не решить, недостижимо |
|---|---|
| **Туша**: как игрок получает тушу взрослого животного. Соединительные волокна есть только в разделке туши | 51 узел, включая гель, шнур, каркас, G0 и всё дальше. **Блокирует сам старт** |
| **«Ручная подложка»** для B12/B14/A01 упоминается, но в списке мест W01–W11 её нет | 42 узла, включая мягкую ткань и мембрану |
| **Открытие функции «сокращение»** для мышечного посева B16 | 23 узла: мышцы и все LV-органы |
| **«Наблюдение оболочечного роста»** для хитиновой культуры B22 | 6 узлов хитиновой ветки |

4. Прочие находки (не кольца):
   - **Посев.** Стартовый посев один, B12 его расходует. Возобновление (ядро: масса мяса + масса растений + 50 ПФ → базовая почка, 120 с) не даёт тупика, если ядро живо и есть N0. Тупик возможен только при гибели ядра; правило восстановления в v0.7 общее, без чисел.
   - **Костный порошок.** Если B09 — ванильная костная мука, то ванильный крафт «1 кость → 3 муки» выгоднее пути B07 + B09 (1 кость → 2 порошка). Нужен единый коэффициент (§22.4 это требует).
   - **Уголь.** Ванильный уголь в мире IIS не генерируется (D12): уголь из GT-руды или древесный из печи. Цепочка от Кибера не зависит, но ранний W05 будет на древесном угле.
   - **Сток и остатки.** Это реальные выходы, переполнение останавливает партию (§22.5). Чем опорожнять их до экологического среза — не описано.
   - **Пасть.** Не ясно, принимает ли она сырую еду или только подготовленные массы. Рецепты кармана требуют массы, а массы — ступу.

## 3. Минимальный следующий срез: «Б-1. Ручная биохимия очага и первый выращенный орган»

Цель — первый полный цикл v0.7 без LV, гидравлики, мутантов и генетики: от еды и туши до мягкой ткани, G0, мембраны, ложа A01 и одного выращенного ULV-органа. Повторяет рекомендацию самой v0.7 (§21.13: «сначала ручной цикл N0/G0 и рост одного F02/F05») на кратчайшем пути. Жидкости, которые для G0 не нужны (экстракт, W0, N1…), не входят.

Предлагаю делать в два шага, каждый проверяем в игре отдельно:

**Б-1a. Карман ядра и мягкая ткань**
- Ядро получает настоящий бак N0 и интерфейс кармана: L01 (N0 + ПФ + сток), L03 (гидролизат), возобновление посева. Стартовый посев и стартовый N0 — на челноке.
- Разделка туши, нож W02, разделочная площадка W01, ступа W03: массы, волокна, рёбра, костный порошок.
- Варочный сосуд W04 и очаг W05: гель (B06). Каркас B10, подложка B11.
- «Ручная подложка» и мягкая ткань B12.
- Жидкости: N0, ПФ, сток, гидролизат.

**Б-1b. G0, мембрана, ложе и первый орган**
- Мерный сосуд W06: взвесь (L04), связующее (L05 на W04 + W05), G0 (L10). Оправка W07.
- Мембрана B14 (на ручной подложке), ростовое ложе A01, далее серийные B13/B14 в ложе.
- Один орган по выбору владельца: A02 пасть (заодно ответ на открытый вопрос D66 «откуда новые пасти»), F05 или F02.
- Жидкости: взвесь, связующее, G0.

**Не входит:** экстракт/W08/F01, F04, W0, N1/E1/G1, все LV-органы, хитин, сосуды, насосы и решатель давления (ULV по v0.7 допускает ручное заполнение), переносные резервуары, мутанты, общая экология и эрозия, генотипы (посев несёт только ID линии и функцию).

**Изменения в действующем коде и почему они нужны:**

| Изменение | Необходимость |
|---|---|
| `ColonyState`: «единицы питания» → N0 в мБ из бака ядра; логика роста, голода, тревоги и `TissueGraph` без изменений; старые миры переводятся по коэффициенту | Без настоящего N0 ни один рецепт v0.7 не связывается с колонией. Только если владелец выберет П1 |
| `FeedingMawBlock`: роль по решению П1/Р3 | Сейчас пасть сама кормит ядро, по v0.7 — передаёт пищу в карман |
| Новый тип рецепта Био (`ru.iis.bio.production`, JSON из генератора = машиночитаемая таблица §22.12) и свой бак жидкости | D36: Био не импортирует `machine`. `GtRecipe`/`FluidTank` Кибера не меняются |
| Челнок: стартовый посев и N0 в ядре | П6 |

**Приёмка Б-1 (автоматические проверки):** таблица рецептов без повторов ID и колец (проверка графа переходит в JUnit). GameTest:
- L01 даёт ровно 350 N0 + 50 ПФ + 100 стока;
- полный путь «туша → гель → подложка → B12 → G0 → B14 → A01 → орган» без Кибера;
- переполненный выход ставит партию на паузу;
- поломка и перезагрузка не дублируют посев и выход;
- колония живёт на N0 так же, как сейчас на «единицах».

Проверка владельцем — по инструкции в `docs/BIO_TESTING.md`, которую обновлю по итогам.

**Объём:** 7 жидкостей, около 16 предметов, около 7 мест/блоков с интерфейсами, ложе и один орган. Это несколько сессий, поэтому срез и разбит на два шага.

## 4. Решения, без которых Б-1 нельзя реализовать

| # | Вопрос | Варианты | Рекомендация |
|---|---|---|---|
| Р1 | Берём ли числа §22 для Б-1 как **временный тестовый набор**? | да / да, но с правками / нет | Да, только перечисленные рецепты, с пометкой «не утверждено» |

| Р11 | **Костный порошок** | ванильная костная мука (закрыть дешёвый крафт для Био) / свой предмет | Ванильная мука, но рецепты Био считают 1 кость = 2 порции через W03 |
| Р12 | **Функции посева в Б-1** | только «базовая ткань» (и «поглощение пищи» для пасти); открытие «сокращения» — в LV-срезе | Да |

Не блокирует Б-1, но понадобится позже:
- П2 (заплата покрова);
- П3 (рудный желудок, доверие, личинки и D38 — сохранить как поздние направления?);
- механика «наблюдения» функций;
- экологический срез E0–E1;
- первая мутантная линия (M0–M2, обязательна для перехода LV→MV).
