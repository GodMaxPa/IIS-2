## Этап 7. Дюпы вне окон, сохранение, нагрузка (12.11, ночь)

- **Разбор блоков.** Содержимое любого блока-инвентаря выпадает один раз (`BlockEntity#preRemoveSideEffects`, повторный вызов в наших
  переопределениях ничего не дублирует — стопки при выпадении забираются из слотов). Квантовый сундук переносит в предмет только сжатое содержимое
  (`iis:quantum_content`), два слота выпадают отдельно — дублирования нет. Таблицы добычи с копированием компонентов (12 штук) копируют только жидкости и это содержимое.
- **Перенос предметов.** Предметные трубы двигают предметы транзакцией (вставка и списание вместе), через границу чанка — только в загруженный чанк.
  Погрузчики, космические машины и тоннельный бур сначала вставляют, потом списывают ровно вставленное. Потерь и удвоений не найдено.
- **Автоматические копатели** (ручной и многоблочные буры, тоннельный бур, лазер, электроинструмент) не ломают неразрушимые блоки; путеукладчик ломает только заменяемые.
- **Сохранение.** Тикающие блоки помечают чанк изменённым при каждой смене состояния; без отметки только турель (состояние хранит база) и
  кормовая пасть (состояния нет).
- **Нагрузка** (`scripts/stand.ps1 -DevOnly`, строка `STAND_CHECK load` в `build/stand.log`): стенд со всеми машинами мода, 298 удерживаемых чанков,
  без игроков, 2600 тиков — в среднем 2,99 мс на тик, худший из последних 100 тиков 8,19 мс (предел 50 мс). 32 из 33 структур собраны
  (33-я — коксовая печь, у неё не многоблочный контроллер).
