# Проверка прохождения по квестам (D150)

Пишется автоматически: `python -I tools/quest_walk.py --write` (после `gen_content.py` и `quests.py`). Руками не править.

Квестов в книге: 1862. Нельзя выполнить (предмет не сделать в выживании): **0**. Заперты за ними: **0**. Ссылок на несуществующие квесты: 0. Предметов заданий, которых нет в игре: 0. Наград, которых нет в игре: 0.

Ступень квеста — наименьшая ступень энергии, на которой можно сделать его предметы: без тока (руки, пар, примитивные печи), LV, MV … UV.
