# Выгрузка рецептов из ИИС 1 (D147)

`IISDump.java` — одноразовый мод для Forge 1.7.10: через 100 тиков после старта сервера пишет в `iis1_dump/` рецепты верстака,
печи, все карты рецептов GT, словарь руд и названия предметов, затем выключает сервер. Только рефлексия, чужой код не копируется.

Как повторить: собрать сервер в отдельной папке (Forge 1.7.10-10.13.4.1614 universal + официальный `minecraft_server.1.7.10.jar` +
библиотеки из манифеста Forge), положить `mods`, `config`, `scripts` из архива «ИИС v1.19.1» (без клиентских модов: CustomMainMenu,
betterloadingscreen, ResourceLoader, MapWriter, InGameInfoXML, OptiFine, fastcraft, AromaBackup), скомпилировать мод
(`javac --release 8 -cp forge-universal.jar`), запустить Java 8: `java -jar forge-…jar nogui`.

Результат лежит в `reference/iis1_dump/*.txt.gz`. Формат строк — табуляция:
- `crafting`: вид, класс рецепта, выход, размер, входы (`ore:имя`, `мод:предмет@мета*кол-во`, `null`);
- `furnace`: вход, выход;
- `gt`: карта, входы, жидкости на входе, выходы, жидкости на выходе, длительность, EU/t, особое значение, шансы, особые предметы, флаги;
- `oredict`: имя, предметы; `names`: `мод:предмет@мета`, название, внутреннее имя.
